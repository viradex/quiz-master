# Tests

These tests are for the alpha testing table and should not be included while grading the overall application!
The tests can be error-prone, contain bugs, and have a lack of internal documentation.

**Note:** Since these clients and servers are intended to be extremely basic, they do not contain PING/PONG functionality. If they are connected for too long to the official Quiz Master server/client, they will be automatically disconnected for not sending/receiving the heartbeat messages, so you need to be quick!
